# 🤖 OLX Monitor Telegram Bot

Telegram-бот для моніторингу свіжих оголошень на **OLX.ua** у реальному часі.

## 🚀 Можливості:
* 🔎 **Гнучкий пошук**: моніторинг за будь-якими ключовими словами (наприклад, `iPhone 13`, `MacBook Air M1`, `Велосипед`).
* 💵 **Фільтрація цін**: можливість вказати діапазон цін (від / до / без обмежень).
* 👥 **Багатокористувацький режим**: кожен користувач має свій власний список підписок.
* ⚡ **Миттєві сповіщення**: кожні 2 хвилини бот опитує OLX і надсилає повідомлення з фото, ціною, містом та прямим посиланням на оголошення.
* ⏸ **Керування підписками**: зручне меню перегляду, паузи та видалення підписок в один клік.

---

## 📦 Встановлення та запуск

### 1. Встановіть залежності
```bash
cd /Users/pc/olx_monitor_bot
python3 -m pip install -r requirements.txt
```

### 2. Створіть файл `.env` з вашим токеном
1. Відкрийте [@BotFather](https://t.me/BotFather) у Telegram.
2. Введіть `/newbot` та отримайте токен бота.
3. Створіть файл `.env` у папці проєкту:
```bash
cp .env.example .env
```
4. Відкрийте `.env` та вставте ваш токен:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
CHECK_INTERVAL_SECONDS=120
```

### 3. Запустіть бота
```bash
python3 main.py
```

---

## 📁 Структура проєкту:
* `main.py` — головна точка входу, запуск бота та фонового моніторингу.
* `olx_parser.py` — асинхронний модуль отримання даних через API OLX.ua.
* `database.py` — робота з базою даних SQLite (`aiosqlite`).
* `handlers.py` — обробка команд, діалогів (FSM) та кнопок бота.
* `keyboards.py` — клавіатури інтерфейсу Telegram.
* `config.py` — налаштування та змінні оточення.
